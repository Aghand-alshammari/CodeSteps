01 / افهم الفكرة

ما المتغير؟

تخيّل صندوقًا له اسم، تحفظ فيه قيمة وتستطيع تغييرها لاحقًا. في Java نكتب نوع البيانات، ثم اسم المتغير، ثم القيمة. وتنتهي التعليمة بفاصلة منقوطة ;.

int age = 20;

int هو نوع البيانات، وage اسم المتغير، و20 قيمته.

أنواع ستستخدمها كثيرًا
النوعيخزّنمثال
intعددًا صحيحًا20
doubleعددًا عشريًا19.5
booleanقيمة منطقيةtrue / false
charحرفًا واحدًا'A'
Stringنصًا"Sara"

تُكتب النصوص بين علامتي تنصيص مزدوجتين، والحرف بين علامتي تنصيص مفردتين. لاحظ أن String يبدأ بحرف كبير، وهو نوع مرجعي، أما الأنواع الأربعة الأخرى هنا فأنواع بدائية.

02 / شاهد المثال

غيّر القيمة واطبعها

هذا برنامج كامل. داخل main نعرّف متغيرين، ثم نزيد العمر سنة ونطبع القيم.

public class Main {
    public static void main(String[] args) {
        String name = "Sara";
        int age = 20;
        age = age + 1;

        System.out.println(name);
        System.out.println(age);
    }
}

الناتج المتوقع:

Sara
21

القيمة الجديدة لـ age هي 21. عند تغيير قيمته لا نكتب النوع مرة أخرى.

04 / جرّب بنفسك

بطاقتك الأولى

عرّف متغيرًا نصيًا باسم name يحتوي على اسمك، ومتغيرًا صحيحًا باسم age يحتوي على عمرك، ثم اطبع كل قيمة في سطر. اكتب التعليمات التي توضع داخل main.

مساحة للتدريب والمقارنة بالحَل؛ لا يتم تشغيل الكود أو تصحيحه تلقائيًا. تُحفظ محاولتك في هذا المتصفح عند توفر التخزين.

قد يختلف الاسم والعمر في إجابتك. تأكد من نوع كل متغير وعلامات التنصيص والفاصلة المنقوطة.

String name = "Sara";
int age = 20;
System.out.println(name);
System.out.println(age);
