# CodeSteps

**Learn. Code. Improve.**

موقع تعليمي يساعد المبتدئين على تعلّم البرمجة خطوة بخطوة من خلال دروس مبسطة، وأمثلة عملية، وتمارين تفاعلية. يركز المشروع في نسخته الأولى على لغة **Java**، ويهدف إلى ربط الشرح بالتطبيق ومساعدة المتعلم على متابعة تقدمه.

## حالة المشروع

تتوفر حاليًا صفحة هبوط باستخدام HTML وCSS وJavaScript، مع معاينات لموضوعات Java ودرس تفاعلي كامل للمتغيرات داخل الصفحة عبر الرابط #variables. يتضمن الدرس شرح الأنواع، ومثالًا مع الناتج المتوقع، وسؤالًا بتصحيح فوري وتفسير الإجابة، وتمرينًا مع حل نموذجي. يمكن تسجيل إكمال الدرس والحصول على 10 XP مرة واحدة، وعرض تقدم 1 من 6 دروس (17% بالتقريب). يُحفظ الإنجاز ومحاولة التمرين محليًا في المتصفح عند توفر التخزين. بقية الدروس وحسابات المستخدمين والخصائص الأخرى المذكورة أدناه لم تُنفّذ بعد.

## أهداف المشروع

- تقديم أساسيات البرمجة بطريقة مناسبة لمن ليست لديه خبرة سابقة.
- تقسيم المحتوى إلى دروس قصيرة ومتدرجة.
- تعزيز الفهم من خلال أمثلة الكود والتحديات والاختبارات.
- تحفيز الاستمرار عبر تتبع الإنجاز ونقاط الخبرة (XP).

## المسار التعليمي الأول: Java

تُرتّب الموضوعات من الأساسيات إلى مقدمة البرمجة الكائنية:

1. **Variables:** المتغيرات وأنواع البيانات.
2. **If Statements:** الشروط واتخاذ القرارات.
3. **Loops:** الحلقات وتكرار الأوامر.
4. **Arrays:** المصفوفات وتخزين مجموعة من القيم.
5. **Methods:** الدوال وتنظيم الكود وإعادة استخدامه.
6. **Classes:** الأصناف ومقدمة البرمجة الكائنية.

تتضمن كل صفحة درس شرحًا مختصرًا، ومثال كود، وتمرينًا للتطبيق، وحلًا نموذجيًا للمراجعة.

## نطاق النسخة الأولى

النسخة الأولى المقترحة تركز على تجربة تعليمية بسيطة ومتكاملة تشمل:

- تسجيل الدخول وحساب المستخدم.
- مسار Java الأساسي مع الشرح والأمثلة والتمارين.
- اختبارات اختيار من متعدد تُصحّح تلقائيًا.
- تحديات برمجية مع إمكانية عرض الحل النموذجي.
- تحديد الدروس المكتملة وعرض نسبة التقدم.
- نظام مبسط لنقاط الخبرة.

تشغيل كود Java الذي يكتبه المستخدم والتحقق منه تلقائيًا ليس ضمن النطاق الأساسي المقترح؛ يتطلب ذلك بيئة تنفيذ معزولة واختبارات للتحقق من الحلول، ويمكن إضافته في مرحلة لاحقة.

## مثال على تجربة التعلم

1. يدخل المتعلم إلى CodeSteps ويضغط Start Learning.
2. يختار مسار Java ثم يفتح درس Arrays.
3. يقرأ الشرح ويتعرف على مثال لإنشاء مصفوفة:

   ```java
   int[] numbers = {10, 20, 30};
   System.out.println(numbers[0]);
   ```

4. يحاول حل التحدي: «أنشئ مصفوفة تحتوي على خمسة أرقام، ثم اطبع الرقم الأول».
5. يعرض الحل النموذجي ويقارنه بمحاولته.
6. يحدد الدرس كمكتمل، فتتحدث نسبة تقدمه ويحصل على نقاط الإنجاز المخصصة للدرس.

## التحفيز والإنجازات

يمكن تطوير نظام التحفيز تدريجيًا ليشمل:

- **XP:** نقاط خبرة مقابل إكمال الدروس والأنشطة.
- **Streak:** عدد أيام التعلم المتتالية.
- **Achievements:** شارات عند تحقيق أهداف محددة، مثل:
  - First Code — إكمال أول تمرين.
  - 5 Challenges Completed — إكمال خمسة تحديات.
  - Java Beginner Completed — إكمال مسار Java للمبتدئين.

## توجه التصميم

- واجهة حديثة وبسيطة تسهّل الوصول إلى الدروس.
- لوحة ألوان تعتمد على الأبيض والأسود والأزرق، مع لمسات خفيفة من البنفسجي:
  - **الأبيض (`#FFFFFF`):** الخلفية الأساسية وبطاقات المحتوى.
  - **الأسود المائل للرمادي (`#111111`):** العناوين والنصوص الرئيسية.
  - **الأزرق (`#2563EB`):** الأزرار الرئيسية والروابط ومؤشرات التقدم.
  - **البنفسجي (`#7C3AED`):** لمسات محدودة للشارات والإنجازات والعناصر المميزة.
  - **الرمادي الفاتح (`#F3F4F6`):** خلفيات الأقسام الثانوية والفواصل البصرية.
- الحفاظ على وضوح النصوص وتباينها، واستخدام البنفسجي باعتدال ليبقى الأزرق اللون الأساسي للتفاعل.
- عرض واضح للكود مع مراعاة اتجاه النص داخل الأمثلة.
- لوحة تعرض التقدم ونقاط الخبرة والإنجازات.
- شريط تقدم يوضح نسبة إكمال المسار.
- تصميم متجاوب مع شاشات الحاسوب والهاتف.

## التقنيات والتشغيل

تستخدم الواجهة الحالية:

- **HTML:** لبناء صفحات الموقع وتنظيم المحتوى.
- **CSS:** لتنسيق الواجهة وجعلها متجاوبة مع مختلف الشاشات.
- **JavaScript:** لإضافة التفاعل ومنطق الاختبارات وعرض التقدم.

لتجربة الصفحة، افتح ملف `index.html` في المتصفح مباشرة؛ لا تحتاج إلى تثبيت حزم أو خطوة بناء.

- `index.html`: صفحة الهبوط ودرس المتغيرات والتقدم.
- `styles.css`: الألوان والتنسيق المتجاوب.
- `script.js`: معاينات Java، وتصحيح السؤال، وإظهار الحل، وحفظ محاولة التمرين والإنجاز والنقاط في localStorage.

الحفظ الحالي محلي لهذا المتصفح ولا يتزامن مع أجهزة أخرى. عند تعذر التخزين تظهر رسالة توضح أن الحفظ غير متاح. لا يتم تشغيل كود Java أو تصحيحه تلقائيًا، ولا توجد حسابات مستخدمين أو قاعدة بيانات حتى الآن.

## أفكار للتطوير مستقبلًا

- إضافة مسارات للغات برمجة أخرى.
- تشغيل كود Java والتحقق من النتائج تلقائيًا.
- إضافة مستويات وتحديات أكثر تقدمًا.
- توسيع نظام الشارات وأيام التعلم المتتالية.
